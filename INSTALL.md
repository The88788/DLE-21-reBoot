# Установка reBoot на DLE 21

1. Установите DLE 21.0 и сохраните резервную копию своего сайта перед сменой оформления.
2. Скопируйте папку reBoot в каталог templates вашего сайта.
3. В настройках DLE выберите шаблон reBoot. Очистите кеш DLE и браузера.
4. Для обложек карточек используйте дополнительное поле poster типа «Изображение». Если оно не заполнено, используется первое изображение краткой новости.
5. Категории, статьи, теги и опросы настройте штатными средствами DLE. Демонстрационные публикации и база данных в архив не входят.

Проверено на DLE 21.0, PHP 8.3.30, MySQL 8.4.3, Apache 2.4.66 и Chromium. Совместимость с другими версиями DLE не заявляется. Дополнительные PHP-модули и изменения ядра не требуются.

Светлая и тёмная темы уже встроены. Выбор темы и размера текста хранится в браузере. JavaScript, иконки и основные стили локальные; текстовые шрифты загружаются с Google Fonts с системными заменами при недоступной сети.

В шаблон включены два отдельных блока: услуги по доработке DLE и VPS-хостинг. Они подключаются из main.tpl через modules/partners.tpl и выводятся перед футером. Ссылка автора адаптации находится в modules/footer.tpl. Оформление блоков — в css/compat21.css. Всплывающих рекламных блоков нет.
